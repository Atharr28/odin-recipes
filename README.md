# Odin Recipes

This is my first project from The Odin Project, as part of the Foundations course.

## About

Odin Recipes is a simple recipe website. Here, I made recipes for lasagna, pizza, and spaghetti. On this website, you can find descriptions, ingredients, and step-by-step instructions.

## Skills

In this project, I mainly used HTML.

## What I Learned

- Using headings and paragraphs
- Displaying images
- Creating lists
